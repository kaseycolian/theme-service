Theme

Every component, in one theme

This is the demo page used for the themes. The ones that ship here and any you create will be demo'd for you to view during creation in the same format. It exists so you can see a theme in real use before applying it in an app. Pick a theme in the header to see it applied to the page, using the same color tokens your app gets. Every theme in the list passed its WCAG 2.2 AA contrast checks before it was built.

The Markdown docs in this repo tell an agent how to install these themes into a new or existing project — USAGE.md for the prompts, AGENTS.md or the Claude skill for the procedure. They wire your app to the finalized tokens in themes/, so it gets the same theme.css this page runs on.
